# Александр

Пишу настольные утилиты на Python и PySide6: загрузочные носители, работа с EFI и OpenCore.

## Проекты

| Проект | Описание |
| --- | --- |
| [HackicLab](https://github.com/SLEP-KOMP/HackicLab) | GUI-сборщик Hackintosh EFI для Windows: сканирование железа, загрузка OpenCore и кекстсов, генерация `config.plist` с проверкой `ocvalidate`, запись EFI на USB и установщик macOS Recovery |
| [BootForge](https://github.com/SLEP-KOMP/BootForge) | Двухпанельная утилита для записи загрузочных флешек на базе Rufus, с поддержкой нескольких экземпляров |

## Стек

Python, PySide6/Qt, Windows API, PowerShell, PyInstaller, GitHub Actions
